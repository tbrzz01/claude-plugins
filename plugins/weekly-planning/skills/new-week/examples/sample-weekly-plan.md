## Notes on This Sample

This sample demonstrates:

1. **Title**: Clear date in "Feb 3, 2026" format
2. **Priorities Section**: Left mostly blank for user to fill in (can add high-level goals)
3. **Daily Sections**: Monday through Friday with M/D format and Focus line
4. **Carried Over Section**:
   - Tasks from previous week that weren't completed
   - Include original links and context
   - Note which week they were carried over from
   - Grouped by category/project where possible
5. **Team Activity**: Template sections for different pods
6. **Empty Sections**: Notes-derived and Tasks For Next Week left for user to populate

The skill should generate clean, consistent structure that matches this format.
