## Notes on This Sample

This sample demonstrates:

1. **Title**: Clear date in "Feb 3, 2026" format
2. **Priorities Section**: Left mostly blank for user to fill in (can add high-level goals)
3. **Daily Sections**: Monday through Friday with M/D format and Focus line, each followed by its own task table
4. **Task Table Schema**: every task — in Working Tasks, Carried Over, Notes-derived Action Items, and Tasks For Next Week — uses the same seven-column table:

   `| Task | Description | Due Date | Done | Suggested Path to Resolve | What's Needed | What Was Learned |`

   - **Task**: short name/title of the task
   - **Description**: what the task involves, with any links (chat threads, docs, dashboards) and "Carried over from X" context folded in
   - **Due Date**: target completion date
   - **Done**: `[ ]` / `[x]` checkbox, same as before — still scannable and toggleable
   - **Suggested Path to Resolve**: a concrete first step, inferred best-effort from the task name and any linked context; `—` if nothing can be reasonably inferred (never fabricated)
   - **What's Needed**: inputs, people, or access required to start; `—` if unknown
   - **What Was Learned**: always `—` when the plan is created — filled in during/after the week

   Example worked row (from Monday, above):

   | Task | Description | Due Date | Done | Suggested Path to Resolve | What's Needed | What Was Learned |
   |------|-------------|----------|------|---------------------------|----------------|-------------------|
   | Review Q1 goal progress with team leads | Check in with each team lead on their goal status ahead of leadership sync | 2/3 | [ ] | Pull current goal tracker and message team leads for updates | Access to goal tracker | — |

5. **Carried Over Section**:
   - Tasks from previous week that weren't completed, rendered as a table using the same schema
   - Original links and context folded into Description or Suggested Path to Resolve
   - "Carried over from X" note folded into Description rather than a separate sub-bullet
   - Grouped by category/project where possible
6. **Team Activity**: Template sections for different pods
7. **Empty Sections**: Notes-derived Action Items and Tasks For Next Week are pre-seeded with the table header (no rows) and left for the user/skill to populate as the week progresses

The skill should generate clean, consistent structure that matches this format.
