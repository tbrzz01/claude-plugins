## Notes on This Example

This example demonstrates:

1. **Complete Header**: All key information fields filled in
2. **About Section**: Brief description of role and specialization
3. **Notes Section**: Organized by week with onboarding items
4. **First 1:1 Notes**: Capturing initial goals and expectations
5. **30/60/90 Day Goals**: Clear progression plan
6. **Activity Placeholders**: Tables ready to be populated
7. **Context Notes**: Explaining why sections are empty (pre-hire, etc.)

The skill generates this structure, then it can be:
- Updated with real 1:1 notes as meetings happen
- Populated with GitHub/Jira activity via `update-team` skill
- Enhanced with more details over time
